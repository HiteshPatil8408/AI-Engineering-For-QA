# Research references

Last reviewed: 2026-10-10. Content is synthesized with original synthetic examples. Runtime and framework behavior should be rechecked when dependencies or APIs change.

- Python tutorial and environments: https://docs.python.org/3/tutorial/ and https://docs.python.org/3/tutorial/venv.html
- NumPy arrays, broadcasting, dot product, and random generators: https://numpy.org/doc/stable/user/absolute_beginners.html and https://numpy.org/doc/stable/user/basics.broadcasting.html
- Pandas introduction, missing data, groupby, and merges: https://pandas.pydata.org/docs/getting_started/intro_tutorials/index.html
- pytest parametrization: https://docs.pytest.org/en/stable/how-to/parametrize.html
- DuckDB-WASM: https://duckdb.org/docs/stable/clients/wasm/overview
- Pyodide worker execution: https://pyodide.org/en/stable/usage/webworker.html (the course pins 0.27.7; current examples may describe later runtimes).
- GitHub Pages custom workflows: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
- FastAPI tutorial: https://fastapi.tiangolo.com/tutorial/
- Docker fundamentals: https://docs.docker.com/get-started/
- LangGraph overview: https://docs.langchain.com/oss/python/langgraph/overview
- MCP architecture: https://modelcontextprotocol.io/docs/learn/architecture
- OWASP prompt injection: https://genai.owasp.org/llmrisk/llm01-prompt-injection/
- Statistical reasoning: https://www.itl.nist.gov/div898/handbook/

Advanced interview material is an introductory bank, not a substitute for the planned later course lessons. Research for scikit-learn, PyTorch, LlamaIndex, Ragas, DeepEval, and MLflow must be completed when those lessons are authored.
